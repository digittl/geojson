# geojson

Static GeoJSON boundary files for Australia — postcode, suburb, and state boundaries used by digittl mapping and delivery-zone features.

## Files

- `AUSWIDE.geojson` — all-Australia combined boundary
- `Aus Postcode & State.geojson` — postcode + state annotations
- `australian-suburbs.geojson` — suburb boundaries
- `NSW.geojson`, `QLD.geojson`, `VIC.geojson`, `WA.geojson`, `TAS.geojson`, `SA.geojson`, `NT.geojson` — state-level postcode boundaries

No build step required. Files are consumed directly as static assets. See `CODEBASE.md` for file sizes and usage notes.
